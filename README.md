## 🛠️ Troubleshooting Common Issues

### ❌ Black Screen on Startup

If you experience a black screen after installing:

1. **Delete the `dinput8.dll` file** from your game folder
2. Launch the game normally to confirm it works
3. Re-download the DLL from our link
4. Place it back in the game folder
5. Right-click the DLL → Properties → **"Unblock"** if the option appears

### ❌ Game Crashes After TU4 Update

Capcom's Title Update 4 caused crashes for many users. Here's the fix:

1. Ensure you have **v1.5.9.2** (the latest nightly build)
2. Delete any older version of `dinput8.dll`
3. Copy the new one to your game folder
4. **Verify game files** in Steam: Right-click game → Properties → Local Files → Verify Integrity

### ❌ REframework Not Loading

1. Make sure `dinput8.dll` is in the **exact same folder** as your game's `.exe` file
2. Check that you're using the **64-bit** version of the game
3. Disable any antivirus that might quarantine the DLL (add it to exclusions)
4. Run the game **as administrator** (right-click game .exe → Run as Administrator)
