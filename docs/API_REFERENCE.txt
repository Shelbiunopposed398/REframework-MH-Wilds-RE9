For Monster Hunter Wilds, RE9, and all supported RE Engine games

CALLBACK EVENTS
Register these as global functions in your script:

  function OnPresent()          -- Called every frame during ImGui render pass
  function OnPreGuiDraw()       -- Called before RE Engine draws its UI
  function OnPostGuiDraw()      -- Called after RE Engine draws its UI
  function OnUpdate()           -- Called every game update tick
  function OnPreCameraUpdate()  -- Called before camera updates
  function OnPostCameraUpdate() -- Called after camera updates

EXAMPLE: Simple mod
  local sdk = sdk

  local function on_update()
      local player = sdk.get_player()
      if not player then return end

      local health = sdk.get_native_field(player, "Health")
      if health and health < 100 then
          sdk.set_native_field(player, "Health", 1000)
      end
  end

  function OnUpdate()
      on_update()
  end

  function OnPresent()
      imgui.begin("Auto Heal Mod")
      imgui.text("Player health auto-set to 1000")
      imgui.end()
  end

FILE PLACEMENT
  - Autorun scripts: reframework/autorun/*.lua (loaded on game start)
  - Manual scripts: load from the Scripts tab in the overlay
