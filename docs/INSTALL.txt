REFramework Installation Guide
================================
Version: v1.5.9.2
Supported games: Monster Hunter Wilds, RE9, RE4, RE8, RE2, RE3, RE7, DD2, SF6

REQUIREMENTS
- Windows 10 or Windows 11 (64-bit)
- Monster Hunter Wilds or Resident Evil 9 installed via Steam
- DirectX 12 capable GPU
- .NET Framework 4.8+ (for some Lua scripts)

INSTALLATION
1. Download REFramework-Installer.zip from the release page.
2. Extract the archive to a temporary folder.
3. Find the correct .zip for your game:
   - Monster Hunter Wilds: MHWILDS.zip
   - Resident Evil 9: RE9.zip (or RE4.zip if RE9.zip not listed)
   - Resident Evil 4: RE4.zip
   - Resident Evil Village: RE8.zip (in newer builds)
   - Dragon's Dogma 2: DD2.zip
   - Devil May Cry 5: DMC5.zip
   - Monster Hunter Rise: MHRISE.zip
4. Extract the game-specific .zip to reveal dinput8.dll (and other files).
5. Copy dinput8.dll into your game folder (where the game's .exe is located).

GAME FOLDER LOCATIONS
- Monster Hunter Wilds: Steam\steamapps\common\MonsterHunterWilds\
- Resident Evil 9: Steam\steamapps\common\RESIDENT EVIL\
- RE4 (2023): Steam\steamapps\common\RESIDENT EVIL 4 BIOHAZARD RE4\
- RE Village: Steam\steamapps\common\RESIDENT EVIL VILLAGE\
- DD2: Steam\steamapps\common\Dragon's Dogma 2\

VR SETUP (OPTIONAL)
If you want VR support:
1. Extract ALL files from the game zip (not just dinput8.dll).
2. Install the UEVR REFramework plugin.
3. Launch the game and enable VR in the REFramework overlay (Config tab).

LAUNCHING
1. Launch the game normally through Steam.
2. REFramework loads automatically.
3. Press INSERT to toggle the REFramework overlay menu.

UNINSTALLING
1. Delete dinput8.dll from your game folder.
2. REFramework leaves no other files. Your game is back to vanilla.

TROUBLESHOOTING
- Black screen: Update to the latest nightly. Old dinput8.dll + new game patch = black screen.
- Crash on launch: Make sure you only copied dinput8.dll (not VR files) if you don't use VR.
- Overlay not appearing: Press INSERT. Check that dinput8.dll is in the correct folder.
- Lua scripts not loading: Place .lua files in reframework/autorun/ subfolder.

MOD COMPATIBILITY
- REFramework is the prerequisite for most Nexus Mods for Monster Hunter Wilds and RE9.
- Place mod files in the natives/ folder (following the game's directory structure).
- REFramework does NOT conflict with FluffyQuack's Fluffy Mod Manager.
- If using multiple mod loaders, load REFramework first.
