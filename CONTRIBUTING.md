# Contributing to TavernKeep 🏰

Thank you for considering contributing to TavernKeep!

## How to Contribute

1. **Report Bugs:** Open an issue using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
2. **Suggest Features:** Submit ideas via the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).
3. **Submit Code Changes:**
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/amazing-feature`).
   - Run local pytest tests: `python -m pytest tavernkeep/tests -v`.
   - Commit your changes (`git commit -m 'Add amazing feature'`).
   - Push to your branch and submit a Pull Request!

## Development Guidelines
- Keep Python code PEP 8 compliant.
- Ensure all API endpoints have corresponding unit tests in `tavernkeep/tests/`.
- Keep the Web Dashboard UI responsive and framework-free (Vanilla CSS/JS).
